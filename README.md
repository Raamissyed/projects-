# Software Projects

Practical projects and exercises I use to develop my software engineering skills. Each project includes setup instructions, limitations, and a walkthrough of the main concepts.

## Projects

### [Internship Application Tracker](internship-tracker/)

A local Python + SQLite tool for tracking job applications, updating their status, and exporting CSV files. It includes automated tests and a GitHub Actions workflow.

**Learning focus:** relational databases, parameterized SQL, input validation, automated tests, and version control.

> This tracker began as an AI-assisted scaffold for hands-on learning. I am using the [learning checklist](internship-tracker/LEARNING.md) to understand, extend, and test it myself.
